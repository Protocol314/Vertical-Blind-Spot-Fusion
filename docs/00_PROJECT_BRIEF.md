# 00. 연구 개요와 최소 연구 기여

## 1. 국·영문 연구명
- 국문: **단일 2D LiDAR의 수직 관측 사각지대 보완을 위한 YOLO 기반 카메라–LiDAR–경량 의사결정 AI 융합 장애물 탐지 시스템**
- 영문: *Lightweight Decision-AI Fusion of YOLO-Based Vision and a Single 2D LiDAR for Mitigating Vertical Obstacle-Detection Blind Spots*

## 2. 연구 문제

수평 스캔 평면만 관측하는 단일 2D LiDAR는 평면 아래의 저형 장애물과 평면 위의 돌출 장애물을 측정하지 못할 수 있다. 카메라는 이런 물체를 볼 수 있으나 RGB 영상의 객체 박스는 곧바로 정확한 3D 거리나 높이를 의미하지 않는다. 단순히 LiDAR 점을 YOLO 박스에 겹치게 하는 방법은 **카메라에서만 보이는 물체를 폐기하거나, 뒤쪽 벽의 거리를 전경 물체의 거리로 오인**할 위험이 있다.

이번 연구는 한 센서의 검출 누락을 보존하고, 실제 거리와 미확정 거리를 구분하는 작은 의사결정 모델을 이용해 위험 알림 성능을 평가한다.

## 3. 가설
- H1: YOLO 단독 영상 후보를 유지하는 융합은 LiDAR 단독 대비 수직 사각지대의 이벤트 미탐률을 낮춘다.
- H2: 학습형 경량 모델은 같은 사각지대 재현율에서 단순 OR 결합 또는 규칙 융합보다 분당 오경고를 낮춘다.
- H3: 실제 데이터 분포와 입력 결측을 포함해 학습한 로컬 경량 모델은 설정한 후처리 지연 예산에 들어간다.
- H4: 관측 누락·보정 불일치·시간 지연을 명시적으로 보류 처리하여 근거 없는 거리 배정을 줄인다.

## 4. 연구의 정확한 기여
1. **수직 사각지대라는 구체적인 실패 조건**에 대한 실험 시나리오와 독립 정답.
2. 카메라 전용 / LiDAR 전용 / 확인된 융합 / 애매함 / 만료의 **출처 구분을 보존**하는 데이터 계약.
3. YOLO26n 출력·각도별 LiDAR 요약·시간·유효성 마스크를 결합한 **작은 판단기**와 규칙 기반 대조군.
4. **이벤트 미탐, 분당 오경고, 잘못된 거리 대응, p95 지연**을 함께 평가.

**신규성 경계:** 2D LiDAR와 카메라 융합, 과거의 수직 사각지대 보완, 학습형 후기 융합은 이미 연구된 분야이다. ‘최초’·‘3D LiDAR 성능 대체’라는 표현은 하지 않는다. 참고: `docs/02_RESEARCH_AND_NOVELTY.md`.

## 5. 조건·산출물
- 2명, 약 14일; 기존 RPLIDAR C1, Raspberry Pi 4B 8GB, Ubuntu 22.04, ROS 2 Humble; YOLO 추론은 RTX 4060 노트북 우선.
- 예산 최대 100만 원이지만 **추가 구매 최소**; 외부 API를 포함하지 않는 MVP.
- 산출물: 소스·설정·데이터 스키마·세션 기록·4종 비교 평가·실측 지연 로그·시연 동영상·발표 자료.
- 운용 범위: 정지/저속 통제 실험, **안전 인증 또는 자율 제어 아님**.

## 6. 성공의 의미
데모가 움직이는 것만으로 성공 판정을 하지 않는다. **사각지대에서 LiDAR가 놓친 참 장애물을 더 발견하는지, 동시에 오경고와 거리 오류를 감수할 수 있는지**를 분리 보고할 것. 지표 결과는 측정 전 비워둔다.
