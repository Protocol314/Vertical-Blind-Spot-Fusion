## 비기능 요구사항(NFR)

- NFR-01 **정직한 불확실성**: `null`/미확정 상태가 허용된다. 거리 실측과 추정값을 섞지 않는다.
- NFR-02 **시간 정합**: 측정·전송·처리 시각은 분리 저장; 한계 초과 시 오브젝트를 `stale`/`ambiguous`로 처리.
- NFR-03 **재현성**: 같은 rosbag/모델/파라미터로 동일 출력(확률적 추론은 명시적인 결정성 한계 포함).
- NFR-04 **테스트 가능성**: 하드웨어 없는 CI에서도 합성 스캔과 이미지 검출 스텁으로 핵심 로직 테스트.
- NFR-05 **구성 분리**: 모델·보정·임계값·시각화·ROS 인터페이스는 독립적인 모듈.
- NFR-06 **실시간 목표**: 전형적인 C1의 10Hz 입력에 맞는 업데이트를 지향하되, 실제 지연·드롭률 측정 전 달성 주장 금지.
- NFR-07 **보안**: API 키 환경변수 처리, 개인정보·촬영 영상 외부 전송 기본 비활성화.
- NFR-08 **이식성**: Python 3.10 / ROS Humble; GPU가 없어도 fusion core unit test 실행.

## 단일 판단 책임

- `calibration`은 **기하학적 좌표**를 출력한다.
- `association`은 **가능한 대응**을 출력한다.
- `fusion_model`은 **대응 신뢰도 또는 위험 점수**를 출력한다.
- `safety_policy`는 **정책·만료·우선순위**를 결정한다.
- `visualization`은 **의미와 불확실성**을 정확히 표시한다.

## MVP와 확장 순서

**MVP**: 오프라인 replay + YOLO26n + 투영 + 규칙 융합 + camera-only + 로컬 LR/MLP + 정량 평가.  
**Stretch A**: 트래킹/1D CNN·Kalman 필터/온디바이스 CPU 최적화.  
**Stretch B**: 실험적으로 검증된 바닥접점·단안 깊이/virtual costmap.  
**Stretch C**: Jev shadow 비교, 완전 자율 주행 연동은 별도 안전성 프로젝트.
