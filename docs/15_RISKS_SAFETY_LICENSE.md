# 15. 위험성·실험 안전·라이선스·데이터 보호

## 주요 위험과 대응

| 위험 | 결과 | 우선 대응 |
|---|---|---|
| 2D laser의 측정 평면 밖 장애물 | 충돌 가능성 | 영상 후보 유지 / `range=null` |
| 박스 안에 있는 배경 레이저점 오인 | 잘못된 거리 경고 | foreground/background 검증, 불확정 판정 |
| 카메라 단독 오탐 | 불필요한 경고 | neg scene, 모델/룰 비교, 미탐-오탐 tradeoff |
| 카메라 미탐과 LiDAR 누락 동시 발생 | 장애물 미발견 | `UNKNOWN`/감지 불가 영역 공개, 안전 보장 금지 |
| 스캔 타이밍과 영상 시차 | 잘못된 대응 | timestamp·skew 진단 및 만료 |
| 카메라/LiDAR 장착 흔들림 | 보정 붕괴 | 기구 고정, 재검증 마커, calibration hash |
| YOLO/ML 추론 지연 | 낡은 경고 | bounded queue, 지연 로그, TTL |
| 외부 API 장애 | 결과 누락·지연 | Jev 비동기 비교만 |
| 실제 주행환경에서 시스템 오작동 | 인명·재산 피해 | 통제·정지·저속·비승객·물리 정지 수단 |

## 실험 안전 수칙

- 주행을 연결하지 않은 **정지 플랫폼/수동 이동**으로 초기 캘리브레이션·데이터 수집.
- 움직이는 로봇이라면 평탄하고 통제된 공간, 보행자 없는 시험 구획, 저속, 현장 감시자, 긴급 차단 수단.
- 물체와 카메라·LiDAR가 안정적으로 고정되도록 함. 매달린 장애물은 낙하 위험이 없도록 고정.
- 디스플레이의 'SAFE'는 **시험 범위 안의 규칙 판단**이고 전역 공간의 절대 안전 선언이 아님.
- 실제 사람 탑승 이동장치, 공공도로, 법적 안전 규격이 필요한 제품에서 성능 검증 없이 사용 금지.

## 라이선스 및 출처

- Ultralytics YOLO의 오픈소스 라이선스는 **AGPL-3.0** 계열이며, 다른 배포/상업적 이용에 엔터프라이즈 조건이 있을 수 있음. 연구 과제라는 이유로 재배포 의무가 자동 면제되는 것은 아니므로 사용 시점 라이선스·배포 방식 재검토.
- `ultralytics`와 가중치의 라이선스·원본 표기. ROS2/기타 의존성 각 라이선스도 확인.
- 공개 YOLO 데이터셋·KITTI 등의 **사용/재배포 권한은 각 데이터 제공처의 실제 약관**을 확인; 무조건 ZIP에 포함 금지.
- 본 Markdown 설계 패키지는 결과 프로젝트 코드의 라이선스를 자동으로 정하지 않는다. 배포 계획 확정 후 프로젝트 라이선스 선택.

## 개인정보·원격 API

- 촬영 영상에 사람/차량번호/장소가 포함될 수 있어 연구 목적 제한, 접근 통제, 보관·삭제 기준을 정한다.
- `JEV_ENABLED=false` 기본값, `TYPESAFE_API_KEY`는 환경변수 또는 secrets 관리. 로그/ZIP/README에 토큰 하드코딩 금지.
- 실제 Jev 원격 전송 여부와 전송할 필드(영상 vs 비식별 구조화 값)를 사용자가 명시적으로 결정하도록 함.
- 외부 API를 호출하지 않고도 모든 필수 성능을 재현할 수 있어야 한다.

## 유지보수 경계

- 실험 결과와 환경 미확인 상태에서 완제품 안내, 법규 준수·안전 인증 주장 금지.
- 구조화된 위험 점수는 실제 사고 확률이 아닐 수 있음. 모델 calibration 확인 없이 과학적 확률로 표시 금지.
