# 04. 센서 장착과 공간·시간 캘리브레이션

## 좌표 규칙

- ROS `base_link`: x 전방, y 좌측, z 상방.
- `laser`: 스캔 좌표 x 전방, y 좌측, z 상방(**실제 드라이버 frame_id 확인**).
- `camera_optical_frame`: x 영상 우측, y 아래쪽, z 광축 전방.
- `T_camera_laser`: laser 좌표를 camera_optical 좌표로 바꾸는 강체 변환. 변환 이름과 방향을 혼동 금지.
- 좌표계는 mm/cm가 아니라 **미터/라디안**을 기본 단위로 삼는다.

## 내부 보정

1. **체커보드** 여러 거리·위치·자세 촬영; 최소 촬영 품질/커버리지를 메모.
2. OpenCV `calibrateCamera`로 `K`, `D` 추정; 재투영 오차 및 이미지 해상도 기록.
3. 입력 영상의 왜곡 보정 및 모델 리사이즈/레터박스의 좌표 관계를 문서화.
4. 학습/검증 영상에서도 동일한 좌표계로 박스를 되돌린 뒤 LiDAR와 비교.
5. 파라미터 변경 시 `calibration_id`와 파일 해시를 갱신.

## 외부 보정

1. **두 센서가 동시에 관측할 수 있는 수직 평면 표적**을 사용; 체커보드만 카메라에 보이고 LiDAR가 관측하지 못하면 직접 대응은 성립하지 않는다.
2. 레이저의 표적 교차선/거리와 영상 표적의 자세로 `T_camera_laser`을 추정; 초기값은 실제 장착 길이/각도 계측으로 둔다.
3. 입력과 다른 거리·위치에서 2D 점의 영상 투영 위치 검증.
4. 잔차(픽셀), 목표 거리별 경향, 실패 포즈를 기록해 보정의 외삽 범위를 밝힌다.
5. 검증 전 탐지 박스만 믿고 대응을 생성하지 않는다.

## 이상적인 2D LaserScan 투영

각도 `θ`와 유효 거리 `r`에서(이상적 평면):

\[
p_L=[r\cos\theta,\ r\sin\theta,\ 0]^T
\]

카메라 좌표 변환:

\[
p_C=R_{CL}p_L+t_{CL}
\]

왜곡을 제거한 영상의 핀홀 투영:

\[
u=f_x X_C/Z_C+c_x,\quad v=f_y Y_C/Z_C+c_y
\]

`Z_C <= 0` 또는 영상 범위 밖의 점은 버리고, 센서 유효 범위 밖의 값은 별도 invalid로 표시한다. 왜곡이 남아 있으면 `cv2.projectPoints`를 이용해 왜곡 계수를 포함한다. 실제 RPLIDAR C1은 제조사 자료에 피치 특성이 있으므로 이상적인 `z=0` 가정이 현장 상태에 성립하는지 검증해야 한다.

## 관측 가능성과 한계

- LiDAR 광선이 **낮은 물체 뒤의 벽**을 치면 실측 거리는 벽 거리다. 투영된 픽셀이 물체 박스 안에 있더라도 물체 거리로 할당하지 말 것.
- LiDAR 평면 아래·위에 객체가 있어 레이저 반사가 없으면, YOLO는 존재 후보를 주지만 실제 측정 거리/높이를 주지 않는다.
- 영상 박스 하단의 바닥 접점과 알려진 바닥 평면을 사용할 수 있는 경우만 **추정** 거리를 별도 산출 가능; 경사면·가림·매달린 물체에는 적용 금지.
- 카메라만 관측한 물체의 방향을 LiDAR 원점 기준으로 곧장 동일 각도로 취급 금지. 센서 원점이 다르면 거리 가정 없이는 정확한 변환이 불가능.

## 바닥 평면 기반 추정(확장)

바닥이 `n^T x + c = 0`, 카메라 중심 `o`, 영상 역투영 방향 `d`일 때:

\[
x=o+\lambda d,\quad \lambda=-(n^To+c)/(n^Td)
\]

단, `n^T d≈0`면 수치적으로 불안정; `λ<=0`이면 거부. **실측값이 아닌 `estimated_range_m`로 표기**하고 오차를 독립 정답으로 확인한다.

## 게이트 통과 조건

- GT-01 외부 보정의 reprojection error를 held-out 표적에 대해 기록(임계값은 실제 환경 기준으로 결정).
- GT-02 최소 3개 거리, 3개 방위에서 투영이 의도한 물체 표면과 대체로 일치하는지 수치/시각 검증.
- GT-03 카메라/레이저 좌표계 원점·축 방향 체크 테스트, 음의 깊이 투영 거부.
- GT-04 거리를 모르는 영상 후보를 `null`로 출력하는 회귀 테스트.
