# 07. 2D LiDAR 전처리·각도 군집화·영상 대응

## 1. 원본 전처리

1. `/scan`은 그대로 보존한다. 출력된 `ranges`를 보정/덮어쓰기 대신 **내부 복사 표현**으로 정규화.
2. `range_min <= r <= range_max` 및 `isfinite(r)`를 통과한 점만 후보로 사용; 드라이버가 `+inf`를 ‘반사 없음’으로 쓸 수 있으므로 0m 객체로 바꾸지 않는다.
3. `angle_min`, `angle_increment`, 실제 array index를 사용해 광선 각도 계산. 고정 360개 빔 가정 금지; C1은 전형적으로 10Hz·5kHz·0.72°다.
4. 레인지 불연속, 인접 광선 간 거리 차, 최소 군집 크기, 주기적 회전 경계 처리를 통해 2D 점 군집 생성.
5. 너무 작은 군집도 위험 후보로 보존할 수 있지만 노이즈 플래그 부여. 무조건 제거하면 작은 장애물 검출 성능이 떨어질 수 있음.

## 2. 객체와 반사의 연관 후보

- 카메라–LiDAR 보정행렬로 **실측 LiDAR 끝점**을 이미지에 투영.
- 시간적으로 유효하고 같은 시야에 속하는 후보만 고려.
- 객체 마스크가 있으면 마스크, 없으면 박스 내 후보 점을 추출하되 박스 가장자리 축소/정규화 영역을 선택 옵션으로 유지.
- 같은 박스 안 점이라도 앞 물체/뒷 벽이 섞일 수 있으므로 최근접군집·분산·거리 점프·추적 연속성 검증.
- 2개 영상 객체가 같은 점을 요구하면 하나에 확정할 수 없으면 **ambiguous**로 남긴다.

## 3. 관측 상태 정의

| 상태 | 생성 조건 | 실측 거리 |
|---|---|---|
| `confirmed_fused` | 유효한 기하·시간 게이트 + 단일 대응 후보 | LiDAR 군집 거리 사용 가능(출처 `LIDAR_MEASURED`) |
| `camera_only` | YOLO 탐지 유효, 일치하는 신뢰할 만한 LiDAR 반사 없음 | `null`, 출처 `UNKNOWN` |
| `lidar_only` | 실제 LiDAR 군집 관측, 대응할 카메라 검출 없음 | LiDAR 실측 |
| `ambiguous` | 대응 후보 중복·배경/전경 불확정·부분 가림 | 객체 거리는 `null` 또는 별도 측정 후보, 신뢰 확정 금지 |
| `stale` | 시간·tf2·보정 조건 불충족 또는 만료 | 최신 정보로 사용 금지 |

## 4. 가장 중요한 실패 상황

### 낮은 박스 앞에 있는 벽
- 벽이 laser plane을 가로질러 4m에서 검출되고 낮은 박스는 1m 지점에 있을 수 있다.
- 벽의 투영 끝점이 박스 YOLO bbox 안에 있어도 **박스까지 거리를 4m로 지정하지 않는다.**
- 실제 박스 거리를 알 수 없으면 `camera_only` + `range=null`.

### 떠 있는 물체(오버행)
- 낮은 laser plane은 물체 아래를 통과하고, 영상은 위험 후보를 본다.
- 실제 clearance/충돌 여부는 로봇 높이와 객체 3D 높이를 알아야 한다. 영상 박스의 상단·하단 픽셀만으로 이를 확정하지 않는다.
- 경고용 상태를 보수적으로 부여하되, 보조 센서가 없으면 `uncertainty` 표시.

### 작은 반사체 / 유리 / 어두운 물체
- LiDAR 리턴이 불안정하거나 반사되지 않을 수 있다. '카메라 전용'이 곧 '수직 사각지대'를 의미하지 않으므로 **원인 추정은 별도 필드**로 둔다.

## 5. 테스트 케이스

- TC-L01: NaN, Inf, 음수, 0, range_min/max 밖 값은 실측 장애물로 쓰지 않음.
- TC-L02: 빈 스캔에서도 camera-only 객체 보존.
- TC-L03: 4m 벽 + 1m 낮은 박스 => 박스 객체 range=null.
- TC-L04: 스캔 평면에 교차한 박스 실제 반사 => 올바른 거리 그룹.
- TC-L05: 서로 겹친 bbox => 하나의 광선을 두 객체에 확정 배정하지 않음.
- TC-L06: 이미지에 투영되지 않는 뒷면 광선 => 영상 대응 없음.
- TC-L07: 실제 카메라/laser 원점이 달라 image bearing을 동일 lidar bearing으로 복사하는 코드 금지.
