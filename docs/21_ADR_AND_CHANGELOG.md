# 21. Architecture Decision Records / 변경 이력

## ADR-001 (2026-11-17) — 후기/의사결정 융합을 MVP로 선택
- 맥락: 2인, 1–2주, 단일 2D LiDAR, 실시간 융합 검증.
- 결정: YOLO26n 시각 검출 + 기하학적 대응 + 구조화 특징의 규칙/LR/MLP 후기 융합.
- 이유: 데이터 수집과 학습 부담, 이해 가능성, 테스트 가능성.
- 대안: end-to-end 영상+LaserScan 조기 융합, 대규모 BEV/Transformer는 2주 내 검증이 어렵고 실제 3D 깊이 정보가 부족.
- 추후 검토: 1D CNN 또는 객체 mask, 거리 추정 별도 평가.

## ADR-002 — 카메라 전용 객체 폐기 금지
- 결정: `camera_only` / `range=null`을 1급 상태로 유지.
- 이유: LiDAR 스캔 평면 밖에 있는 **주요 연구 대상**이기 때문.
- 결과: 물리 거리와 가상 위험 정보를 별도 관리; 잘못된 거리 대응 테스트 필수.

## ADR-003 — Jev는 필수 경로에서 제외
- 결정: 로컬 tiny model을 핵심 경로로 사용, 원격 Jev는 사용자가 명시 허용한 경우만 shadow 비교.
- 이유: 네트워크 의존성·지연·개인 영상 외부 전송·API 비용.
- 결과: Jev가 없어도 전체 MVP 평가/시연 가능.

## ADR-004 — Pi 수집 + 노트북 YOLO
- 결정: 기존 Pi ROS2 환경 우선 유지. RTX 노트북에서 영상 추론/평가.
- 이유: 초기 파인튜닝/추론 시간 단축과 개발기간 안정성.
- 대안: Pi-only 최적화는 별도 논문 확장으로 보류.

## ADR-005 — 학습과 시험은 세션 단위 분리
- 결정: adjacent frames random split 금지, group-split.
- 이유: 연속 프레임의 데이터 누수와 과장된 정확도 방지.
