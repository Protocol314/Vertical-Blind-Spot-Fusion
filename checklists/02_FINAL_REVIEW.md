# 최종 점검 및 발표 검토 체크리스트

## 기술 무결성

- [ ] 실제 LiDAR `/scan`이 변형되지 않는다.
- [ ] camera-only는 유지되며 잘못된 실측 거리로 승격되지 않는다.
- [ ] 원본 영상 좌표와 YOLO bbox, 투영좌표가 일치한다.
- [ ] time sync 및 calibration quality를 측정/기록했다.
- [ ] 벽 뒤 저형 물체 시나리오에서 배경 거리를 물체 거리로 할당하지 않았다.
- [ ] 센서 고장·timeout·오래된 데이터에 대응.

## 연구 설계

- [ ] 데이터셋/실험 환경/실제 표본 수 공개.
- [ ] B0 LiDAR-only, B1 YOLO-only, B2 OR, B3 Rule, B4 Learned 비교.
- [ ] 수직 사각지대별 이벤트 재현율/미탐·오경고 기록.
- [ ] 단순히 mAP만 말하지 않고 e2e 지연/데이터 age/거리 출처 오류를 보고.
- [ ] 결과표의 모든 숫자는 raw log와 git sha를 역추적 가능.
- [ ] 편향·보정·장면 누수·단일 실험실 장면 한계 서술.
- [ ] tiny AI가 규칙보다 낫지 않다면 개선 실패를 있는 그대로 보고.

## 제품·안전·라이선스

- [ ] 3D LiDAR 동등 성능·실사용 안전 인증 주장하지 않음.
- [ ] 저속 통제된 환경에서만 데모.
- [ ] Ultralytics/데이터셋/모델 라이선스와 재배포 의무 검토.
- [ ] 토큰·영상 데이터·개인정보·대용량 weights를 허가 없이 공개하지 않음.
- [ ] 실제 Jev와 Jev형 로컬 모델을 혼동하지 않음.
- [ ] 발표 제목·결론이 **실제로 구현/측정한 것**과 정확히 일치.
