# 현장 데이터 수집·라벨링 체크리스트

## 녹화 시작 전

- [ ] LiDAR↔카메라 장착이 흔들리지 않음.
- [ ] `K`, `D`, `T_camera_laser`, 버전/해시를 현재 장비에 맞게 선택.
- [ ] 원본 frame·scan의 timestamp·시간 domain 일치 확인.
- [ ] 촬영 장소, 시간, 조도, 바닥 경사, 표적 물리 크기·높이 계측.
- [ ] 로봇의 충돌 높이·폭을 GT 기준으로 정의.
- [ ] 촬영 인물/장소 개인정보·촬영 허가 확인.

## 녹화 중

- [ ] 전형적인 LiDAR 10Hz 유지 여부와 camera FPS 확인.
- [ ] 별도의 저형/중간/상부/안전 통과/빈바닥/배경 벽 시나리오 모두 기록.
- [ ] 실제 거리·장애물 높이를 줄자 등으로 기록.
- [ ] 카메라 검출 여부와 laser plane 교차 여부를 독립적으로 라벨.
- [ ] 센서 드롭·조도 변화·타임스탬프 이상을 기록.

## 수집 후

- [ ] `session_id`와 원본 rosbag/영상/GT JSONL 연결.
- [ ] SHA256/동영상 길이/스캔 수·프레임 수 요약.
- [ ] GT의 `unknown`을 임의로 음성(비위험) 라벨로 변환하지 않음.
- [ ] 학습/검증/시험을 session/scene/physical_object 단위로 분할.
- [ ] 중복·인접 프레임 데이터 누수 점검.
- [ ] 결과표에 실제 측정 여부(REAL/SYNTHETIC) 명시.
