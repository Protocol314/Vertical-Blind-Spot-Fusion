## 복사해서 사용할 프롬프트

당신은 ROS 2 Humble·센서 융합·Computer Vision·실시간 추론을 구현하는 시니어 연구 개발 에이전트다.

**작업 목적:** 현재 프로젝트 루트의 Markdown 설계 패키지를 기반으로, 단일 2D LiDAR(RPLIDAR C1) + RGB 카메라 + YOLO26n + 경량 의사결정 모델을 결합하여 수직 관측 사각지대의 장애물 미탐률을 분석하는 **재현 가능한 연구 소프트웨어**를 구축한다.

먼저 **`AGENTS.md`, `CLAUDE.md`, `README.md`, `docs/00_PROJECT_BRIEF.md`, `docs/01_REQUIREMENTS_SCOPE.md`, `docs/10_DATA_AND_INTERFACE_CONTRACTS.md`, `docs/18_ACCEPTANCE_CRITERIA.md` 전체를 읽어라.** 이후 나머지 docs와 prompts를 조사하고, 구현 계약과 작업 순서를 이해하라.

**절대 조건:**
- `/scan` 실측 거리를 변경하거나 영상만 본 물체에 존재하지 않는 LiDAR 거리를 붙이지 않는다.
- `camera_only` 객체를 `range_m=null` 상태로 보존한다.
- 센서 내부·외부 캘리브레이션과 시간 정합을 경량 AI 판단과 분리한다.
- 실제 Jev API는 사용자의 명시적 허용이 없다면 호출하지 않는다. 로컬 LR/MLP를 주 경로로 한다.
- 학습 정답과 데이터 스플릿의 누수를 방지한다. 사실과 목표·추정을 분리한다.
- 기존 Raspberry Pi ROS2 환경·사용자 작업물을 지우거나 바꾸지 않는다.
- 원본 입력 없이 실제 정확도·지연 측정값을 만들어내지 않는다.

**진행:**
1. 현재 코드와 실행 환경을 안전하게 점검하라. 없으면 소스 프로젝트 스캐폴드부터 생성하라.
2. `docs/17_ENGINEERING_BACKLOG.md`를 세부 실행 계획으로 삼되, `prompts/01_SCAFFOLD.md`부터 **한 단계씩** 구현하라.
3. 모든 단계에서 **ROS 없이도 테스트 가능한 순수 Python core**를 최우선으로 만든다.
4. 하드웨어가 없어도 synthetic fixture/replay로 데이터 계약과 핵심 알고리즘을 검증하라.
5. 각 단계가 끝날 때 변경 파일, 실행한 테스트 명령과 결과, 남은 위험, 다음 작업을 요약하라.

먼저 읽은 자료 요약과 현재 소스/장비 접근성 점검을 출력하고, 단계 01 구현을 진행하라. 사용자에게 이미 있는 정보를 반복해서 묻지 말고 미확정 장비 정보는 config TODO로 남겨라.
