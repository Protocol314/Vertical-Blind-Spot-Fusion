# PHASE 09 — Codex ↔ Claude Code 작업 인수인계 프롬프트

이 파일은 두 에이전트 중 하나가 구현한 뒤 다른 에이전트가 이어서 작업할 때 사용한다. 이전 대화 내용이 없어도 저장소만으로 진행할 수 있어야 한다.

## 복사 프롬프트

이 저장소는 **Vertical Blind-Spot Fusion** 연구 구현 중이다. 이전 코딩 에이전트의 대화를 볼 수 없다고 가정하라.

1. 먼저 `AGENTS.md`, `CLAUDE.md`, `README.md`, `PROJECT_STATUS.md`, `docs/17_ENGINEERING_BACKLOG.md`, `docs/18_ACCEPTANCE_CRITERIA.md`, `docs/21_ADR_AND_CHANGELOG.md`를 읽는다.
2. 현재 파일 트리, git status/최근 커밋, 테스트 설정·실제 시험 로그를 확인하라. 이미 구현된 기능을 파괴하거나 복제하지 않는다.
3. 단계 완료 체크박스는 **테스트 증거**와 대조하고, 증거가 없다면 상태를 미검증으로 둔다.
4. 다음 미완료의 가장 작은 P0/P1 작업 하나를 구현하라. 기능 추가보다 데이터 출처·거리 불확실성·시간 정합 회귀 테스트를 먼저 보강하라.
5. 위험도 모델의 선택이 바뀌어도 카메라 전용 후보가 삭제되거나 가짜 LiDAR 거리로 확정되지 않게 하라.
6. 실제 Jev API는 선택적·비동기 비교만 허용; 승인 없이는 호출하지 않는다.
7. 끝나면 다음 내용을 `HANDOFF_NOTES.md`에 기록하라: 진행 단계, 변경 파일, 재현 명령, 실제 로그/커밋 ID, 통과/실패 테스트, 미확정 장비 정보, 다음 담당자의 바로 다음 한 가지 작업.

요약 후 선택한 작업을 즉시 진행하라. 이전 채팅을 알아야만 가능한 상태를 남기지 마라.
